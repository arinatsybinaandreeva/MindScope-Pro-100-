# 🧠 MindScope Pro — 100+ психологических тестов

Ссылка на игру: https://arinatsybinaandreeva.github.io/MindScopePro100/

Как играть:
1. Перейдите по ссылке
2. Сохраните на рабочий стол

Работает офлайн, бесплатно, без регистрации. Просто открой файл в браузере.

Интерактивное веб-приложение с **108 научно-обоснованными психологическими тестами**, работающее полностью офлайн прямо в браузере. Без регистрации, без сервера, без интернета — просто открой файл и проходи тесты.

## ✨ Возможности

- 🧪 **108 методик** — от классических (Айзенк, Big Five, MBTI, Бек) до современных (резильентность, самосострадание, тёмная триада, копинг-стратегии)
- 📊 **Психологический портрет** — автоматическая сводка сильных сторон, зон риска и проблемных мест
- 📈 **Динамика во времени** — графики изменения результатов при повторных прохождениях
- ⏰ **Напоминания о пересдаче** — у каждого теста свой интервал (от 2 недель до года)
- 🎯 **Корректный подсчёт баллов** — учитываются реверсивные вопросы и подшкалы
- 💬 **Развёрнутые интерпретации** — каждый результат объясняется простым языком
- 📱 **Адаптивный дизайн** — удобно на телефоне и компьютере
- 💾 **Хранение истории** — все результаты сохраняются в localStorage

## 🚀 Быстрый старт

1. Скачай файл `index.html`
2. Открой его в любом браузере (Chrome, Firefox, Safari, Edge)
3. Проходи тесты и смотри свой портрет

Никаких зависимостей, кроме [Chart.js](https://www.chartjs.org/) (подключается через CDN).

## 🛠 Технологии

- **HTML5 + CSS3** — адаптивная вёрстка, тёмная тема
- **Vanilla JavaScript** — вся логика без фреймворков
- **Chart.js** — графики динамики
- **localStorage** — сохранение результатов и истории
